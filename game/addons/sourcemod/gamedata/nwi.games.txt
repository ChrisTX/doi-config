// What nwi_gamedata.sp calls and hooks in the game, for Day of Infamy and Insurgency, which share all of
// it. Linux by symbol; Windows by signature, as its libraries have no symbols.
//
// physenv: the server's physics environment (IPhysicsEnvironment *), read anew at each use. On Windows
// it comes from PhysFrame, which starts by comparing it with 0 (cmp dword ptr [physenv], 0 at +6, its
// address at +8). The slots of its timestep methods are those of the SDK's IPhysicsEnvironment
// (public/vphysics_interface.h); on Windows, the virtual destructor takes one slot instead of GCC's two,
// so they're one lower (PhysFrame calls Simulate through slot 34 on Windows, 35 on Linux).
//
// CBaseServer::GetMasterServerPlayerCounts(int &humans, int &maximum, int &bots) computes the counts
// the server reports; CSteam3Server::SendUpdatedServerDetails passes them on to Steam, which answers
// the server browsers' queries (A2S) with them. Windows: the call before the "players : %i humans, %i
// bots (%i/%i max)" line of status, the same signature in both games' engine.dll.
//
// The playlists: CPlaylists (g_Playlists, the object) reads them in UpdateCache, which makes a Playlist
// for each playlist and ruleset (CPlaylists::GeneratePlaylist: its key and ruleset first, then SetData).
// Playlist::SetData(KeyValues *) copies the file's data to the Playlist's own (m_data) and goes on to
// GenerateCoalescedData, which merges the ruleset's blocks into a copy that every Get*() reads. The
// key is the playlist's name in sv_playlist, e.g. nwi/coop_commando. KeyValues::SaveToFile and
// LoadFromFile take the IBaseFileSystem part of g_pFullFileSystem (IFileSystem), 4 bytes in, after
// IAppSystem's vtable pointer; DoI's SaveToFile has a fourth parameter (bool) the SDK lacks. Linux
// only so far.
//
// CServerUGCManager::IsEnabled: whether the server uses the workshop. In Day of Infamy, only
// CDOIPersistence::RegisterServer asks, which then doesn't register the server for the game's stats.
