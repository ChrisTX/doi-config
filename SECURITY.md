# Security policy

## What to report here

Security problems of this configuration and its scripts: settings that let players take over a server (rcon, cvars, admin flags), scripts or systemd units that leave the host open (permissions, secrets, downloads that aren't verified), or anything else that would let someone get further than they should.

Vulnerabilities of the game, SourceMod, Metamod:Source, SourceBans or the plugins belong upstream, to the project's own security policy.

Only the current state of the `main` branch is supported.

## How to report

Please report privately, not in a public issue:

- with GitHub's [private vulnerability reporting](https://github.com/ChrisTX/doi-config/security/advisories/new), or
- by email to cpfeiffer at rev-crew dot info.

Say what is affected, and how. You'll get an answer within a week; once a fix is on `main` and the servers are updated, the report can be disclosed.
